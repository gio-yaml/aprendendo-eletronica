# 📚 Recursos para estudar eletrônica

Não existe uma ordem certa para aprender eletrônica. Se você prefere entender os fundamentos antes de praticar, comece pelos cursos e materiais teóricos.
No meu caso, fiz o caminho contrário: comecei pela prática e, conforme fui me interessando pelos projetos, busquei a teoria para entender o porquê das coisas.
Escolha o método que fizer mais sentido para você. O importante é encontrar uma forma de aprender que mantenha sua curiosidade e vontade de continuar.


# 🛒 Componentes que mostro no vídeo

Se você está começando, **esse é o kit que eu mais recomendo**.

A ideia é comprar um kit que já venha com vários componentes que serão utilizados nos primeiros projetos, como:

- Microcontrolador
- Jumpers
- LEDs
- Resistores
- Sensores
- Protoboard
- Botões
- Outros componentes eletrônicos

Isso é importante porque você não vai ficar apenas estudando a teoria: **vai conseguir dar sentido aos seus projetos e colocar os conhecimentos em prática.**

Por exemplo, em vez de simplesmente aprender o que é um LED, você poderá montar projetos para:

- Acender e apagar um LED;
- Controlar a intensidade de um LED de acordo com o valor de um sensor.
- Utilizar um botão para controlar um LED;
- Criar um semáforo utilizando sensores;
- Medir valores de sensores;
- Criar pequenos projetos de automação.

Assim, cada componente que você aprender terá uma **aplicação prática** e você conseguirá entender como trabalha com cada módulo.

 **Dica:** não precisa comprar todos os componentes de uma vez. Comece com um kit que permita fazer vários projetos diferentes e vá aumentando sua coleção conforme novos projetos exigirem componentes específicos.

## 🧪 Simuladores

### 4. Wokwi

Use o Wokwi para montar e testar circuitos virtualmente, especialmente projetos envolvendo microcontroladores (gosto de usar ele quando envolve Esp32, raspberry pi pico)

[Acessar o Wokwi](https://wokwi.com/)

### 5. Tinkercad

Outra ferramenta de simulação bastante interessante para quem está começando.

É ótima para aprender a trabalhar com **protoboard, componentes eletrônicos e Arduino** sem precisar comprar tudo inicialmente. Bom também para fazer testes antes de decidir os sensores para um projeto específico

[Acessar o Tinkercad](https://www.tinkercad.com/)
